2. ⌨️ Ask a question

input() asks the user to type something.

name = input("Your name: ")
print("Hi", name)

Remember: name is a variable. It stores information.

3. 🔢 Work with numbers

int() changes a whole-number text input into an integer.

age = int(input("Age: "))

Choose the correct answer: What does int() do?

Quick calculation: print(5 + 4) shows...

4. 🚦 Make a decision

if checks a condition. elif checks another condition. else is used when the earlier conditions are false.

score = 65
if score >= 80:
    print("Excellent")
elif score >= 50:
    print("Pass")
else:
    print("Try again")

What will the program show?

Look carefully: Python needs a colon : after if, elif and else. The next line must be indented.

5. 🛠️ Fix the code

This code has a mistake:

if age >= 12
    print("Welcome")

What is missing?

Correct code:

if age >= 12:
    print("Welcome")

6. 🐢 Meet Turtle

Turtle is a Python tool that draws lines and shapes.

forward(100) = move forward
right(90) = turn right
left(90) = turn left
penup() = move without drawing
pendown() = draw again

Which command turns right?

7. 🎨 Draw a square

Tap the button to watch the square being drawn.

import turtle
t = turtle.Turtle()
for i in range(4):
    t.forward(100)
    t.right(90)

Why do we use range(4)?
